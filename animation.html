Video Resource Builder

Write an AI search prompt for course videos, confirm every video is publicly playable, then export the collection as embed code, a standalone page, or Canvas-ready HTML.

⏱ 20 min 🧲 3 steps 🎯 Tool

What this makes and when to use it

This tool turns a topic description into a curated set of verified YouTube videos and hands you three ready-to-paste outputs: individual embed snippets, a complete standalone HTML page, and a Canvas-safe block. Reach for it when you want video in a course and need every link to still work in week nine — because it checks each video against YouTube before you build anything, which is the step that catches the private, deleted, and hallucinated IDs an AI assistant will hand you.

Before you start

What You Will End Up With

One block of HTML per video, wrapped in a responsive 16:9 container so it scales on a phone. The same collection is also emitted as a full downloadable page and as a Canvas-sanitiser-safe fragment.

    Step 1 output. The tool assembles a structured search prompt. The opening and the part that matters most — the anti-hallucination block — look like this:
    
      
    
        
    
          Generated prompt (excerpt)
          
        
    
        
    I am building an educational video resource and need you to find 3
real, publicly available YouTube videos on the following topic.

== TOPIC ==
Supply and demand curves in microeconomics, focused on price elasticity

== AUDIENCE ==
Introductory (100-level)

== VIDEO REQUIREMENTS ==
- Number of videos needed: 3
- Preferred length: 5-15 min
- Additional priorities: Reputable source; Has captions

== IMPORTANT INSTRUCTIONS ==
- Do NOT invent or hallucinate video IDs. Use web search to confirm
  each video actually exists.
- If you cannot find a real video that fits, say so - do not
  substitute a placeholder.

    Judge it
    
      
    How to Tell Good Output From Bad
    
      
    The tool will happily build a beautiful page around a bad collection. These are the checks it cannot make for you.
    

      
    
        
    A good collection
    
        
      
          
    • Every card came back Valid & Public in Step 2, and you opened at least one in a private window to confirm it plays without a login.
      • 
          
    • Each video carries a display label a student can act on — “Elasticity, the total revenue test”, not “Econ video 2”.
      • 
          
    • The context line names when and why to watch: before which class, which minutes matter, what to bring back.
      • 
          
    • Total runtime is proportional to the assignment. Three 8-minute videos is a homework task; three 40-minute videos is a week.
      • 
          
    • Discussion questions you have read and edited. The resistance ratings are experimental; they are a starting draft, not a vetted assessment.
      • 
          
    • The videos have real captions, not auto-generated ones, if any student in the section needs them.
      • 
        
    
      
    

      
    
        
    Signs the output needs work
    
        
      
          
    • You skipped Step 2 and pasted IDs straight from the assistant. Roughly one in three AI-suggested IDs in testing was wrong, private, or removed.
      • 
          
    • A card reads Video is private or restricted and you kept it anyway — it renders as a grey box for every student.
      • 
          
    • Every question sounds the same across videos. Reshuffle, change the context chips, or switch resistance level.
      • 
          
    • High-resistance questions on a developmental section: they ask students to locate and evaluate outside sources, which is a different assignment.
      • 
          
    • The Canvas paste looks fine in the editor but blank when published — your institution has iframe embeds disabled. Test in a sandbox page first.
      • 
          
    • The downloaded page opens with no video frames: you opened it from a file path while offline. The page chrome is self-contained, but YouTube itself still needs the network.
      •
