Usage Tips

          
How to embed in your LMS and make the most of this tool

        

      

      

        

          🎨
          
Canvas

          
In the Rich Content Editor, click the HTML Editor button (<>) and paste the generated code. Switch back to the visual editor to verify it looks right.

        

        

          📚
          
Moodle

          
In any text area, click HTML mode (the source icon) and paste the code. Your site admin may need to enable iframe support in Moodle's security settings.

        

        

          📱
          
Mobile Testing

          
Always test on mobile devices after embedding. Use width="100%" and a fixed height (e.g., 600) for the best cross-device experience.

        

        

          🔒
          
Security

          
Use HTTPS URLs whenever possible. If embedding interactive tools with JavaScript, you may need "Allow scripts" in sandbox settings. For static content, more restrictive settings are safer.

        

        

          🌐
          
GitHub Pages

          
This tool works on GitHub Pages. GitHub-hosted pages generally embed well in LMS platforms. Use your username.github.io/repo URL as the content source.

        

        

          ♿
          
Accessibility

          
Always fill in the Title field — it's required for screen readers. Use a descriptive title that tells students what the embedded content is about.
