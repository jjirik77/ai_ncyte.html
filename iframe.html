LMS Iframe Generator

Turn any published HTTPS address into a valid, accessible embed code you can paste straight into Canvas, Moodle, or Blackboard.

⏱ 10 min 📑 4 sections 🎯 Tool

What this makes and when to use it

This tool writes the <iframe> tag that places a live web page — your GitHub Pages site, an interactive activity, a video collection — inside an LMS page, so students use the resource without leaving the course. Reach for it once you have a working HTTPS address and want the resource embedded rather than linked, because an embed keeps students in one place and always shows the current version of the source.

Before you start

What You Will End Up With

A single block of HTML, about eight lines long. You paste it into your LMS HTML editor and save. Nothing gets uploaded and nothing gets hosted by the LMS — the tag simply points at the address you already published.

Finished artifact 
<iframe
  src="https://alexrivera-edu.github.io/comm101-resources/"
  width="100%"
  height="600"
  frameborder="0"
  allowfullscreen
  title="COMM 101 Course Resource Hub"
  loading="lazy"
></iframe>

Judge it

      
How to Tell Good Output From Bad

      
Before you paste an embed into a live course, check it against these five criteria. Four of them are invisible until a student hits them.


      

        
A good embed

        
    
          
  • Carries a title that names the content, not the technology — “COMM 101 Course Resource Hub”, never “embedded page”.
    • 
          
  • Uses an https:// address. Browsers silently refuse to load an http:// frame inside an https:// LMS page.
    • 
          
  • Is tall enough that the inner page does not scroll inside a scroll. Nested scrollbars are the single most common student complaint.
    • 
          
  • Renders in the preview panel here and in a sandbox page in the real LMS. This tool and Canvas apply different sanitisers.
    • 
          
  • Still works when signed out. Open the source address in a private window — if it asks for a login, so will the embed.
    • 
        

      


      

        
Signs the output is wrong

        
    
          
  • The preview panel stays blank: the source sends X-Frame-Options: DENY and cannot be embedded at all. Link to it instead.
    • 
          
  • The URL box shows a red border: the address is malformed — usually a missing https://.
    • 
          
  • The interactive parts are dead: the sandbox setting is too strict. Move up to “Allow scripts and same origin”.
    • 
          
  • The title field is empty: the tool will omit the attribute entirely, which is a WCAG 4.1.2 failure in a graded course page.
    • 
        

      

    


    
    

      
In practice

      
Usage Tips

      
How to embed in your LMS and make the most of this tool.

      

        

          🎨
          
Canvas

          
In the Rich Content Editor, select the HTML Editor button (<>) and paste the generated code. Switch back to the visual editor to verify it looks right.

        

        

          📚
          
Moodle

          
In any text area, select HTML mode (the source icon) and paste the code. Your site admin may need to enable iframe support in Moodle's security settings.

        

        

          📱
          
Mobile testing

          
Always test on mobile devices after embedding. Use width="100%" and a fixed height (for example 600) for the best cross-device experience.

        

        

          🔒
          
Security

          
Use HTTPS addresses whenever possible. If embedding interactive tools with JavaScript, you may need “Allow scripts” in sandbox settings. For static content, more restrictive settings are safer.

        

        

          🌐
          
GitHub Pages

          
This tool works on GitHub Pages. GitHub-hosted pages generally embed well in LMS platforms. Use your username.github.io/repo address as the content source.

        

        

          ♿
          
Accessibility

          
Always fill in the Title field — it is required for screen readers. Use a descriptive title that tells students what the embedded content is about.
